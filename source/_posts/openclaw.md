Hello 大家，我是 Joey。

最近这个 OpenClaw 真的很火，好多人都在聊。我自己也玩上了，今天就给大家带来一个简单的安装教程。

其实网上的教程非常多，我今天主要就是想记录一下自己折腾的过程，仅此而已。

## 1\. 忠告：不要在本地裸奔

从我个人的角度，我现在还是不建议大家直接在本地电脑（主力机）上运行的。

毕竟 AI Agent 的权限很大，目前来讲这可能不太合适。我们还是找一台没什么用的闲置服务器，丢上去会比较安全。哪怕有一些风险，也是都在一个隔离的环境里。

如果你没有闲置服务器，想在本地玩，那强烈建议分配一个虚拟机 (VM)。官方作者也是这么想的，隔离环境更安全一点。

废话不多说，我们直接开始。

## 2\. 系统准备

环境大家随意，但我最近比较喜欢用 Ubuntu。确实比较适合我这种小白来操作，系统干净，报错少。

确保你登录进来了，而且环境足够干净，不用担心信息泄露。

## 3\. 安装与初始化

我们直接把官方的一键脚本粘贴到终端里。这个脚本会自动检测环境，非常省心：
[code]
    curl -fsSL https://openclaw.ai/install.sh | bash  
    ---
[/code]  
  
接下来就是全自动的流程，非常舒服。

遇到安全警告（Security Warning），系统问你知不知道这玩意有风险？  
选 Yes 也可以，反正我们在隔离环境里。

## 4\. 搞定 OpenAI 认证（OAuth）

这一步是安装过程中稍微需要动一下手的地方。因为 VPS 没有浏览器，没法直接弹窗验证。

  1. 选择 OpenAI Codex (ChatGPT OAuth)。
  2. 终端会给你一串超长的 URL。
  3. 把这串 URL 复制到你本地电脑的浏览器打开，登录你的 OpenAI 账号。
  4. 授权成功后，浏览器会跳到一个打不开的 `localhost` 链接。
  5. 把那个打不开的地址完整复制下来，粘贴回服务器的终端，回车。

这里系统会提示：`Paste the redirect URL`。你就把刚才复制的地址贴进去就行。

## 5\. 连接 Telegram Bot

既然是 Cloud Bot，肯定得接个聊天软件。我们选 Telegram，最简单。

不想在 TG 里搜索的话，可以直接点这个链接跳转：  
<https://t.me/BotFather>

进去之后：

  1. 发送 `/newbot`
  2. 给机器人起个名字（用户名必须以 bot 结尾）
  3. 拿到 HTTP API Token

把这个 Token 粘贴到终端里提示 `Enter Telegram bot token` 的地方。

## 6\. 技能配置：全选 No

到了选技能（Skills）这一步：

一路按空格、回车，选 No。

为什么？因为我们现在的目标是先让它跑起来。这就是我这两天玩出来的核心逻辑：让机器人自己改自己。等它跑起来了，缺什么插件，你直接在对话框里命令它装就行了，不用现在费劲。

## 7\. 最关键一步：配对 (Pairing)

安装完成后，你在 TG 里给机器人发消息，它会高冷地回你一句：  
`OpenClaw: access not configured. Pairing code: LJ7N3HR7`

这就对了。为了安全，必须在服务器端批准你的账号。

回到终端，执行这条命令（记得换成你自己的 Code）：
[code]
    openclaw pairing approve telegram 你的配对码  
    ---
[/code]  
  
看到终端显示 `Approved`，那就大功告成了。

## 8\. 效果展示

现在你的助手已经可以正常使用了。

它最牛逼的地方在哪里呢？就是它可以操控你的机器。

比如，我现在想把这台 Ubuntu 的系统语言改成中文。以前我得去查 `locale` 命令怎么写，现在我直接在 TG 里跟它说：

> “把系统语言改成中文。”

它就会自己在后台噼里啪啦敲命令。等它回我 “完成了”，我回终端一看，报错提示都变成中文了。

好了，教程就到这，大家有闲置机器的赶紧去试试。
