一、准备工作

1、VPS一台重置好系统  
2、下载SSH连接工具Finalshell：[【点此进入】](https://www.hostbuf.com/t/988.html)  
3、作者开源项目地址：[【点此进入】](https://github.com/alireza0/s-ui)  
4、请自行放行VPS需要使用到的端口，部分VPS需要在已购VPS官网的控制台放行端口，如未成功放行搭建时所需要的端口，可能会造成搭建失败！  
5、如搭建后出现报错或节点不能正常使用，建议根据视频检查是否有遗漏！

* * *

二、SSH连接VPS执行以下命令：

1、必要的更新(Debian/Ubuntu)
[code]
    apt update -y && apt install -y curl socat wget
[/code]

2、必要的更新(centos系统)
[code]
    yum update -y && yum install -y curl socat wget
[/code]

* * *

三、安装S-UI面板
[code]
    VERSION=v1.3.7 && bash <(curl -Ls https://raw.githubusercontent.com/alireza0/s-ui/$VERSION/install.sh) $VERSION
[/code]

* * *

四、伪装域名

1、测试挑选 SNI 伪装域名

### 测试挑选 SNI 伪装域名

换一批 复制
[code]
    for d in mscom.demdex.net ts1.tc.mm.bing.net github.gallerycdn.vsassets.io www.amd.com bing.com cdn77.api.userway.org intel.com tag.demandbase.com prod.pa.cdn.uis.awsstatic.com se-edge.itunes.apple.com ; do t1=$(date +%s%3N); timeout 1 openssl s_client -connect $d:443 -servername $d </dev/null &>/dev/null && t2=$(date +%s%3N) && echo "$d: $((t2 - t1)) ms" || echo "$d: timeout"; done
[/code]
