> A prompt template for generating 3 commercial ad creatives from product images, logos, and reference styles.  
>  用于从产品图、Logo和风格参考图，一键生成3张商业广告图。

<aside>

请根据我上传的：  
1）产品图  
2）品牌 Logo  
3）参考风格图

一次生成 3 张不同风格的商业广告图。  
每张图必须作为独立完整广告成品输出。

要求：

  * 自动分析产品卖点
  * 自动生成营销广告视觉
  * 自动生成适合销售的构图与场景
  * 保持品牌一致性
  * 产品主体清晰突出
  * Logo 自然融入画面
  * 保持高级商业广告质感
  * 适合 Facebook、Instagram、TikTok、小红书、抖音和电商平台广告投放
  * 避免低质量 AI 感
  * 保留文案排版留白

每张图必须：

  * 不同场景
  * 不同构图
  * 不同销售角度
  * 不同广告氛围

用户指定场景：{例如：海边度假 / 办公室 / 健身房 / 高级浴室 / 客厅 / 户外}

用户指定风格：{例如：Luxury / Minimal / Apple 风 / 小红书风 / 高级棚拍 / Cinematic}

CTA 文案：{例如：立即购买 / 限时优惠 / 免费咨询 / 了解更多}

电话号码：{填写电话号码}

输出比例：{例如：Ratio 1:1 / 4:5 / 9:16}

产品补充信息（可选）：{产品描述 / USP / 使用优势 / 关键差异点}

额外要求：

  * CTA 必须自然融入广告排版
  * 电话号码清晰可见
  * 文字排版具有商业广告设计感
  * 不要出现乱码或无法识别的文字
  * 保持整体高级简洁风格
