# 教程开始

## 第一步、烧录ImmortalWrt到tf卡，并给R3S安装系统

如果你是哈利的同款设配：烧录软件(rufus) + 镜像文件(immortalwrt) 已经在“所需软件”部分为你准备好，请自行下载。  
如果你不是哈利的同款：请到此处自行搜索您所需的镜像 <https://firmware-selector.immortalwrt.org/>

### 烧录操作：

将tf卡插入读卡器，连接电脑 => 打开 rufus 会自动检测到你的tf卡 => 选择镜像文件开始烧录

### 安装操作：

首先插入tf卡，然后给盒子通电。这点很重要！先插卡，在通电。这样他才会读取卡中的系统，如果先通电，它会直接读取自带的友善的系统。先插卡，在通电后，我们观察system灯，先单凭闪烁，再常亮。常量后，就说明系统已经加载完成，我们拿一根网连接它的lan口，lan口啊，别搞错了，另一头连接自己的电脑。输入这个地址进入盒子管理页面，默认密码为空。
[code]
    #盒子管理页面
    http://192.168.1.1/cgi-bin/luci/   
    #默认密码 为空
[/code]

## 第二步、让R3S盒子取代路由器

lan口，我们已经配置好了，接下来是wan口，把原本插在小米路由器上的网线拔下来，插入r3s小盒子的wan口。在R3S后台管理页面中修改wan口的网段为2，此时R3S的后台管理页面地址就变为了：
[code]
    #盒子管理页面
    http://192.168.2.1/cgi-bin/luci/ 
[/code]

此时我是可以打开百度、抖音 等国内网站的。

如果你没有动过你们家的光猫，那90%的人是可以正常使用网络的。但也会有10%的人不能正常上网。这是因为光猫有两个功能，一个信号转换，也就是拨号，一个是流量转发，也就是路由。运营商一般会默认把两个功能都放在光猫里，这样他们就省事了。但是你在使用的时候会连接路由器，这样路由器转发一次，光猫再转发一次。会出现双重nat，导致网路变慢。所以有人会把拨号功能后移到路由器之中来避免双重nat。但今天我不打算将这个问题，下一个视频我会讲几个跨境电商工作室提升网速的方法，这个问题我们放到下一期视频中解决。如果你是那10%，请你自行把拨号功能放回到光猫之中。

## 第三步、把小米路由器利用起来

拔掉电脑连接小盒子的线，插入小米路由器的Lan口，进入路由器后台，

后台地址大概率是这个：[http://192.168.31.1](http://192.168.31.1/)

上网设置 =》 工作模式切换，选择有线中继。保持这个页面不要动。再找出一根网线，一头连接小盒子的lan口，另一头连接小米路由器的wan口。 点击下一步。此时你的手机，再连接小米路由器发出的WiFi，就可以访问国内网络了

## 第四步、在软路由中安装代理

进入r3s盒子的管理页面 系统 => 软件包
[code]
    #盒子管理页面
    http://192.168.2.1/cgi-bin/luci/ 
[/code]

在软件包中安装以下插件
[code]
    luci-i18n-ttyd-zh-cn  #命令行工具（非必选）
    luci-theme-argon      #界面美化工具 （非必选）
    luci-i18n-passwall-zh-cn # 代理工具（必选）
[/code]

打开 服务 => PassWall 添加 自己的节点，TCP选择自己的节点，开启主开关。就可以实现所有连接这个WiFi的设备都使用该节点。实现全员翻墙。

如果你没有节点，或者找不到靠谱的住宅IP节点，可以看看这家公司 [千宿科技 100%独享住宅IP提供商](https://cloud.qsuyun.com/aff/KQXPRHCX) 。这是我见过号称有 CN2和GIA 线路 最便宜的服务商了，每月最低20/元人名币。他们的客服承诺，如果不是独享住宅IP，愿意吃粑粑。

## 第五步、给每台设备指定一个IP，1对1隔离

先将自己的节点导入，然后来到“规则设置”里，自己创建分流规则

源地址：输入自己的设备的IP地址  
域名输入：regexp:.*  
IP输入：0.0.0.0/0
