**0\. 简介**

`Clash`是一款用 Go语言 开发的支持 Linux/MacOS/Windows/Android 等多平台的代理工具，支持 ss/v2ray（不支持 ssr），支持规则分流（类似于 Surge 的配置）。

由于客户端长期更新中可能出现界面或功能与教程不符，我们建议您把本教程仅作为参考，具体需要根据自己使用过程中熟悉了解。

[![](https://cdn.jsdelivr.net/gh/mt-theme/metron-assets@3.0.2/metron/media/tutorial/mac/clashr/clashr.png)](https://cdn.jsdelivr.net/gh/mt-theme/metron-assets@3.0.2/metron/media/tutorial/mac/clashr/clashr.png)

**1\. 下载安装客户端**[  下载 Clash 客户端](https://sabrinathings.lanzous.com/iP1hbkcd6hi)

下载并进行拖动安装

在启动台开启应用,如有弹窗务必点确定,有密码就输入

[![](https://cdn.jsdelivr.net/gh/mt-theme/metron-assets@3.0.2/metron/media/tutorial/mac/clashr/01.png)](https://cdn.jsdelivr.net/gh/mt-theme/metron-assets@3.0.2/metron/media/tutorial/mac/clashr/01.png)

**2\. 设置订阅地址**   Clash 订阅配置     ClashR 订阅配置  

点击上方按钮一键导入节点配置到Clash

Config Name 填入 好家伙 - Cloud

点击确定，如果弹出配置错误信息，请重启Clash 后重试。(请确保您已购买套餐)

无法一键导入? 试试手动设置订阅

依次点击 `配置` - `托管配置` - `管理` - `添加`

将订阅地址粘贴到 URL 一栏, Config Name 填入 好家伙 - Cloud - 确定

[![](https://cdn.jsdelivr.net/gh/mt-theme/metron-assets@3.0.2/metron/media/tutorial/mac/clashr/02.png)](https://cdn.jsdelivr.net/gh/mt-theme/metron-assets@3.0.2/metron/media/tutorial/mac/clashr/02.png)

**3\. 开启代理**

点击勾选 `设置为系统代理` 开启代理

[![](https://cdn.jsdelivr.net/gh/mt-theme/metron-assets@3.0.2/metron/media/tutorial/mac/clashr/03.png)](https://cdn.jsdelivr.net/gh/mt-theme/metron-assets@3.0.2/metron/media/tutorial/mac/clashr/03.png)
