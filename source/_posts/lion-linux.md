## 使用方法

### 安装基础组件

**Debian/Ubuntu**

`apt update -y  && apt install -y curl`

**CentOS/RedHat/Fedora/AlmaLinux/Rocky Linux**

`yum update && yum install -y curl`

**Alpine Linux**

`apk update && apk add curl`

  

### 运行脚本

`bash <(curl -sL kejilion.sh)`
