bash <(curl -fsSL <https://raw.githubusercontent.com/kejidao19-lang/npm-extra-https/main/install-npm-extra-https.sh>)你 VPS 上直接跑这个：

bash <(curl -fsSL https://raw.githubusercontent.com/kejidao19-lang/npm-extra-https/main/install-npm-extra-https.sh) 

安装完以后，命令就是：

npm-extra-https 

再添加端口：

npm-extra-https 36339 

删除端口：

npm-extra-https --remove 36339 

你这个仓库里已经有 .gitattributes 了，后面再更新脚

  

如果面板安装这个对接节点需要清理一下

直接写一条 **一键清理残留 xboard-node 的命令** ，包括停止服务、杀掉进程、删除文件和端口检查：清理面板崩溃，然后对接服务器的问题

[![](https://blogger.googleusercontent.com/img/a/AVvXsEikO39XjQIZ3SD89iLBTp5u6iwg-TAgDWJm9auXhHClwGK-A4RN0gs27LhrpQZsFplWr-BhmsGvW10_6Mt_z0HTlos90HAQrghwN89f6V2lvKUgn85nXQgPGqddtAyphc4iSxvHV6BZC2I_Yru6Fhn-WFBa1UVJ-zXF5axsOVjuiOXjgkY77Ew67Ib0wdmG)](https://blogger.googleusercontent.com/img/a/AVvXsEikO39XjQIZ3SD89iLBTp5u6iwg-TAgDWJm9auXhHClwGK-A4RN0gs27LhrpQZsFplWr-BhmsGvW10_6Mt_z0HTlos90HAQrghwN89f6V2lvKUgn85nXQgPGqddtAyphc4iSxvHV6BZC2I_Yru6Fhn-WFBa1UVJ-zXF5axsOVjuiOXjgkY77Ew67Ib0wdmG)

  

```
 
    sudo systemctl stop xboard-node.service; sudo systemctl disable xboard-node.service; \  
    pkill -f xboard-node; \  
    sudo rm -rf /etc/xboard-node /var/lib/xboard-node /usr/local/bin/xboard-node; \  
    sudo lsof -i :65530

```

说明：

  1. 停止并禁用 systemd 服务。 
  2. 杀掉所有 `xboard-node` 相关进程。 
  3. 删除配置文件、数据目录、可执行文件。 
  4. 检查端口 65530 是否已释放（如果命令无输出表示已释放）。 

执行完这条命令后环境干净，可以直接重新运行安装脚本。
