# 隐私协议

本站（码境，l4535.de5.net）非常重视你的隐私。

## 我们收集什么

- **访问统计**：本站使用 Umami 进行匿名访问统计，只记录页面浏览量、访问来源等聚合数据，不收集姓名、邮箱、IP 等个人信息。
- **评论**：留言使用 Giscus（基于 GitHub Discussions），发表评论需要登录 GitHub 账号，评论内容及你的 GitHub 公开信息会展示在对应页面下，具体以 GitHub 的隐私政策为准。
- **Cookie**：本站除评论与统计所需的最基本 Cookie 外，不主动设置追踪 Cookie。

## 我们不做什么

- 不出售、出租或分享你的个人信息。
- 不在站内投放第三方广告追踪器。

## 联系方式

如对本协议有任何疑问，可通过留言板联系站长。

*本协议最后更新于 2026 年 11 月 26 日。*
