# 简介

之前做过一期使用海外住宅IP的方法，导致很多跨境电商或做tk的粉丝咨询我。也由于那一期视频是购买服务器，自己搭建节点的方法，更多的是适用于我个人，那我个人不仅要使用服务器的ip，我还要做一些web3 depin项目，做个网站，做个网盘 什么的。没有考虑到大部分跨境 tk 的商户，他们不需要服务器，他们只想要 将自己的流量 被转发成住宅ip，这一个功能。所以，这一期视频，我想仅针对于这些跨境的小商户，请不起技术人员的小商户。来讲讲如何把自己的电脑伪装成海外住宅IP。那本期视频运营起来一个号的成本，将比上期视频，大大降低啊。

我们只讲两个场景，  
1、我一个人同时运营多个tk号，一个卖衬衫，一个卖首饰，一个卖比基尼。但是不做直播。  
2、我一台电脑运营一个tk号，要用直播软件直播。

# 视频教程

# 第一步、购买住宅IP

1、住宅IP VPS：[千宿科技 100%独享住宅IP提供商](https://cloud.qsuyun.com/aff/KQXPRHCX) 。这是我见过号称有 CN2和GIA 线路 最便宜的服务商了，每月最低20/元人名币。他们的客服承诺，如果不是独享住宅IP，愿意吃粑粑。

![](https://hali.life/wp-content/uploads/2025/06/%E5%BE%AE%E4%BF%A1%E6%88%AA%E5%9B%BE_20250601155022.jpg)

2、IP服务商：[IP2World全球IP代理 官网](https://www.ip2world.com/?ref=N3JL27CTTB)

# 第二步、Clash For Windows 开启 TUN 模式

下载clash for windows： [clash下载连接](https://pan.quark.cn/s/ea115d3b2867) (若下载后没有exe文件，请到下方“具体参考中寻找下载地址”)，然后购买一个VPN并导入clash。  
具体操作请参考我这一篇：<https://hali.life/?p=97>

最后 一定要开启 tun模式，tun模式会在本机开启一个虚拟网卡，并接管本机所有流量，达到全局代理的目的。

# 第三步、修改本机代理指向住宅IP

在第一步购买住宅IP后，会得到 IP，端口，账号，密码，并设置白名单（此时，账号密码不中要，白名单重要。白名单必须是tun模式中的固定IP）然后来到自己的windows设置：  
设置 => 网络和Internet => 代理 => 手动设置代理 => 填入你购买的住宅IP和端口  
如果你是按照我的推荐使用ip2world服务商，此处端口填入：2000  
此时你的电脑全部流量都将走你买的住宅IP代理。你此时可以使用直播软件进行直播。

# 第四步、一人一台电脑运营多个账号，不开直播

需要使用指纹浏览器：[比特浏览器 官网](https://www.bitbrowser.cn/?code=7e16ef)

多开，然后在每一个实例中填写自己购买的住宅IP，账号，密码，IP，端口。
